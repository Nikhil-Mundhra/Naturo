# Naturo Digital Visiting Card & QR Generator

Digital business card viewer and Python vCard / QR code generator.

## Components
- **`generator.py`**: Python script to generate standard vCard 3.0 file and high-resolution QR code PNG.
- **`web/index.html`**: Mobile-responsive interactive digital business card.
- **`assets/harish_mundhra.vcf`**: Base64 photo-embedded vCard contact file.

## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Generate QR Code and vCard
```bash
python generator.py
```

Outputs:
- `harish_mundhra.vcf`
- `harish_mundhra_qr.png`
